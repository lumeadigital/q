# CYBER SHIELD 🛡️
### تحدّي الأمن السيبراني — اكتشف الاحتيال!
**مشروع تفاعلي سريع وموجّه للبوثات والمعارض الطلابية بجامعة الحسين بن طلال**

---

## 🌟 نظرة عامة
لعبة ويب تفاعلية صُممت خصيصاً لتعمل بسلاسة فائقة داخل المتصفح (100% Offline / Client-Side) دون الحاجة لأي خادم أو اتصال إنترنت أو مكتبات خارجية. تُحاكي اللعبة رسائل تصيّد إلكتروني (Phishing) ورسائل آمنة (Safe) لاختبار وعي الطلاب في دقيقة واحدة وبطريقة شيقة تناسب شاشات اللمس واللابتوب.

---

## 📁 هيكلية ملفات المشروع
```text
cyber_shield_project/

└── README.md         # دليل التشغيل والتخصيص
```

---

## 🚀 طريقة التشغيل على نظام Windows (خطوات بسيطة جداً)

1. فك ضغط المجلد المضغوط `cyber_shield_project.zip`.
2. انقر نقراً مزدوجاً (Double Click) على ملف:
   ```text
   index.html
   ```
3. سيفتح المشروع مباشرة في متصفحك الافتراضي (Google Chrome أو Microsoft Edge).
4. **نصيحة لشاشة العرض أو شاشة اللمس في البوث:**
   - اضغط مفتاح **F11** في لوحة المفاتيح لتشغيل وضع ملء الشاشة (Full Screen) لتبدو كبرنامج مستقل احترافي تماماً!

## ⚙️ التعديل وإضافة أسئلة جديدة
يمكنك إضافة أي سؤال جديد بسهولة بالغة من خلال فتح ملف `script.js` بأي محرر نصوص (مثل Notepad أو VS Code):

ابحث عن المصفوفة:
```javascript
const QUESTION_BANK = [
    // أضف كائن جديد بالشكل التالي:
    {
        id: 6,
        type: "نوع الرسالة (مثلاً: إشعار تطبيق بنكي)",
        icon: "📱",
        sender: "اسم المرسل وبريده التوضيحي",
        subject: "عنوان الموضوع",
        body: "نص الرسالة التي ستظهر للطالب",
        linkUrl: "https://example-domain.com/path",
        isPhishing: true, // ضع true إذا كانت احتيال، أو false إذا كانت آمنة
        explanation: "التفسير التعليمي الذي يظهر فور إجابة الطالب"
    }
];
```

## 🔒 معايير الأمان والخصوصية
- **حماية الخصوصية:** لا يجمع المشروع أي بيانات من الطلاب إطلاقاً.
- **سلامة المحاكاة:** جميع الروابط المعروضة عبارة عن نصوص محاكاة تعليمية ونطاقات وهمية ولا ترتبط بأي برمجيات خبيثة فعلية.
- **بدون إنترنت:** يعمل الكود مستقلاً بدون مكتبات خارجية (Pure Vanilla JS).
